# TMDB-CLI-Tool
This project is a command-line application (CLI) that consumes the The Movie Database (TMDB) movie API
and displays the movies in the terminal.


It helps me practice my programming skills such as JSON manipulation, API consumption, and CLI development.

### How to use?
You only need to run the application command with the type parameter.
```bash
    tmdb-app --type "playing"
    tmdb-app --type "popular"
    tmdb-app --type "top"
    tmdb-app --type "upcoming"
```
